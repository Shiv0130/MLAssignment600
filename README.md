# Machine Learning 600 — Credit Risk Prediction

Richfield Graduate Institute of Technology — BSc IT (Articulation).

Classifies loan applicants as **low-risk (0)** or **high-risk (1)**.

## Files
- `main.py` — Parts A–F (inspect, EDA, clean, PCA, 6 models, GridSearchCV on Decision Tree)
- `credit_risk_dataset.csv` — dataset (add locally if not in this repo yet)
- `Credit_Risk_Prediction_Presentation.pdf` — presentation

## Run
```bash
pip install pandas numpy matplotlib scikit-learn
python main.py
```

Libraries: numpy, pandas, matplotlib, scikit-learn only.
